## Bundled Syncthing

The packaging script downloads unmodified Syncthing **v2.1.5**, licensed under
**MPL-2.0**, as a separate executable. Source code for that exact version is
available under MPL-2.0 at https://github.com/syncthing/syncthing/tree/v2.1.5
and https://github.com/syncthing/syncthing/archive/refs/tags/v2.1.5.tar.gz.
Recipients may obtain and modify that source under the MPL. The upstream license
is reproduced in THIRD_PARTY_LICENSES.txt, and fetch-syncthing.sh also retains
syncthing-LICENSE.txt alongside the binary. Any future modifications to covered
files must be made available under MPL-2.0. Verify corresponding source availability
for each release. The binary also links Go's standard library and runtime and 54
third-party Go modules (one replaced by a fork, whose licence is the one taken),
among them Apache-2.0 modules whose NOTICE files must accompany it.
THIRD_PARTY_SYNCTHING.txt lists every one and reproduces its license, notice and
patents files, as described for restic below.

## Bundled restic

The packaging script downloads unmodified restic **0.19.1**, Copyright (c) 2014,
Alexander Neumann, licensed under **BSD-2-Clause**, as a separate executable. Source
for that exact version is at https://github.com/restic/restic/tree/v0.19.1. The
upstream license is reproduced in THIRD_PARTY_LICENSES.txt, and fetch-restic.sh also
retains restic-LICENSE.txt alongside the binary. The binary also links Go's standard
library and runtime and 79 third-party Go modules under their own licenses, among
them Apache-2.0 modules such as minio-go whose NOTICE files must accompany it.
THIRD_PARTY_RESTIC.txt lists every module linked into the bundled binaries, as Go
records them in each binary's build info (the same for darwin and linux on arm64
and amd64), and reproduces every license, notice and patents file from each
module's exact-version source, plus Go's own. scripts/go-notices.sh generates it,
and the same files for Syncthing and the tunnel. publish-macos.sh refuses to put
a binary in the app that links anything its file doesn't cover, and CI checks the
same on what it fetches and builds.

## Tunnel and Go dependencies

The tunnel uses **tailscale.com v1.102.4**, Copyright (c) 2020 Tailscale Inc & AUTHORS,
under BSD-3-Clause. Its license and upstream dependency manifest are included in
THIRD_PARTY_LICENSES.txt. The manifest describes upstream CLI/daemon builds; it is
not an exact list of packages linked into Uncloud's custom tsnet tunnel. go.mod
and go.sum pin the module graph. THIRD_PARTY_TUNNEL.txt is that exact list: the 37
modules linked into the tunnel's builds for darwin and linux on arm64 and amd64
(not every build links every one), with every license, notice and patents file
from each, including nested ones, and Go's own, generated by scripts/go-notices.sh.
A module's root license does not establish the license of all of its subpackages,
which is why nested files are kept; native code linked on a platform still needs
reviewing for each release.

## Distribution and audit limits

package-macos-app.sh copies LICENSE and all root THIRD_PARTY_* files into the app's
Contents/Resources/Licenses before signing. Keep them with redistributed bundles.
This collection is an inventory and notice baseline, not a complete compliance
certification. Missing separate notice files are visible in the inventories;
check upstream README/file headers where a tarball has no standalone license.
Regenerate/review notices whenever dependencies change. No blanket GPL/AGPL grant
is being applied to Uncloud. Exact Go/native/runtime release coverage is pending.
